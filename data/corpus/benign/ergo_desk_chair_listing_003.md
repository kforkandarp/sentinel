# ErgoSit Pro Commercial Task Chair

## Overview
The ErgoSit Pro task chair is engineered for 24/7 continuous corporate duty cycles. Built with aerospace-grade nylon mesh and reinforced alloy gas cylinders.

### Feature Matrix
- **Lumbar Support:** Independent dynamic 2D lumbar tracking
- **Armrests:** 4D adjustable (height, depth, width, and pivot angle)
- **Recline Mechanism:** Multi-position synchronized tilt lock (90° to 135°)
- **Casters:** 65mm heavy-duty dual-wheel polyurethane casters suitable for hardwood and carpet
- **Load Capacity:** BIFMA certified for users up to 136 kg (300 lbs)
