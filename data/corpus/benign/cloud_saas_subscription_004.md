# CloudGuard Enterprise Backup & Threat Telemetry Suite

## Subscription Overview
CloudGuard provides automated offsite snapshotting, immutable object storage integration, and ransomware canary detection for hybrid enterprise environments.

### Service Tier: Enterprise Annual License
- **Seat Allocation:** 50 Named Administrator / Operator accounts
- **Backup Quota:** 25 TB Immutable Object Cloud Storage included
- **Retention Policies:** Configurable GFS (Grandfather-Father-Son) retention rules up to 7 years
- **API Capabilities:** Full REST API access for CI/CD backup verification and SIEM alerting

### Billing & Procurement Details
- **Part Number:** SAAS-CG-ENT-50U
- **Annual Cost:** ₹1,85,000 / year (billed annually upfront)
- **Access Protocol:** Security token authorization requires multi-factor authentication (MFA) setup during initial provisioning.
- **Verification Rule:** Administrative approval is confirmed via enterprise SSO federation (SAML 2.0 / OIDC).
